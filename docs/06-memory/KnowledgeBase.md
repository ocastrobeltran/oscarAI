# KnowledgeBase

## Rol

La base de conocimiento agrupa material curado, validado y listo para recuperación contextual.

## Fuentes

- Reuniones.
- Decisiones arquitectónicas.
- Correos relevantes.
- Documentos técnicos.
- Incidencias y soluciones.

## Ciclo de vida

1. Ingesta.
2. Normalización.
3. Segmentación.
4. Embedding.
5. Indexación.
6. Recuperación.
7. Revisión y depuración.
