# Memory

## Objetivo

La memoria permite que Oscar AI retenga contexto útil sin convertir cada interacción en una sesión aislada.

## Capas

- Memoria transaccional: estado de trabajo inmediato.
- Memoria persistente: datos relevantes y reutilizables.
- Memoria semántica: conocimiento recuperable por similitud.

## Principios

- Guardar solo lo que aporta valor futuro.
- Versionar el conocimiento crítico.
- Evitar duplicar verdad entre bases.
- Distinguir entre hecho, hipótesis y borrador.
