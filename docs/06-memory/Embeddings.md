# Embeddings

## Objetivo

Representar conocimiento textual y documental en vectores para búsqueda semántica.

## Reglas

- Fragmentar por sentido, no por tamaño arbitrario.
- Conservar metadatos del origen.
- Versionar el contenido original para poder reconstruir contexto.
- Eliminar duplicados o casi duplicados cuando no aporten valor.

## Riesgos

- Fragmentación excesiva.
- Ruido semántico por documentos mal estructurados.
- Ingesta de información sensible sin control.
