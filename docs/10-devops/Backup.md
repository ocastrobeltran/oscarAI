# Backup

## Objetivo

Proteger datos relacionales, configuraciones y conocimiento persistente.

## Componentes a respaldar

- PostgreSQL.
- Qdrant.
- Configuración crítica.
- Artefactos operativos si son parte del negocio.

## Reglas

- Probar restauración.
- Cifrar copias.
- Definir retención.
- Separar backup de datos y backup de configuración.
