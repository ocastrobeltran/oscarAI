# MCP

## Rol

MCP es la capa estándar preferida para conectar herramientas externas con Oscar AI.

## Estrategia

- Usar MCP siempre que exista servidor adecuado.
- Usar API nativa cuando MCP no cubra la necesidad.
- Encapsular credenciales y permisos por integración.

## Beneficios

- Menor acoplamiento.
- Mayor reutilización.
- Integración homogénea.
