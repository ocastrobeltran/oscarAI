# UX Principles

## Objetivo

Definir criterios de experiencia para un dashboard que debe ser útil para supervisión, revisión y acción rápida.

## Principios

- Priorizar lectura inmediata.
- Mostrar primero lo urgente y lo bloqueante.
- Reducir densidad visual cuando el estado sea estable.
- Evitar widgets sin una acción clara asociada.
- Mantener consistencia entre el dashboard y los reportes.

## Secciones recomendadas

- Estado global.
- Riesgos y bloqueos.
- Trabajo reciente.
- Acciones pendientes.
- Resumen de integraciones.
