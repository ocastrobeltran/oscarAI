# ADR-003: Qdrant como base vectorial

## Estado

Aceptado

## Contexto

La plataforma necesita búsqueda semántica sobre documentos, reuniones y conocimiento operativo.

## Decisión

Usar Qdrant para almacenar embeddings.

## Almacenará

- Actas
- Correos
- PDFs
- Word
- Excel
- Reuniones
- Soluciones técnicas

## Beneficios

- Búsqueda semántica.
- API sencilla.
- Integración natural con RAG.
