# ADR-004: Arquitectura basada en agentes

## Estado

Aceptado

## Contexto

Un único asistente crecería en complejidad y sería difícil de mantener.

## Decisión

Implementar agentes especializados coordinados por un orquestador.

## Agentes iniciales

- PM Agent
- QA Agent
- Documentation Agent
- Meeting Agent
- Communication Agent
- Legger Agent

## Beneficios

- Responsabilidades claras.
- Escalabilidad.
- Reutilización.
