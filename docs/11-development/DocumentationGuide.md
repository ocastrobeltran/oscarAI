# Documentation Guide

## Objetivo

Definir una forma consistente de escribir, versionar y enlazar la documentación de Oscar AI.

## Reglas de estilo

- Un documento, una responsabilidad principal.
- Encabezados cortos y semánticos.
- Referencias cruzadas en lugar de duplicación.
- Diagramas Mermaid para decisiones y flujos relevantes.
- Redacción orientada a lectura de equipo, no a relleno narrativo.

## Convenciones de nombre

- ADR-XXX-Theme.md para decisiones arquitectónicas.
- Topic.md para documentos temáticos.
- README.md para índices y navegación.
- Template-*.md para plantillas reutilizables.

## Convenciones de contenido

Cada documento técnico debe intentar responder, como mínimo:

1. Qué problema resuelve.
2. Qué decisión o diseño propone.
3. Qué relaciones tiene con otros artefactos.
4. Qué límites o riesgos introduce.

## Versionado

- Los documentos estables deben evolucionar con cambios pequeños.
- Las decisiones importantes deben reflejarse en ADR.
- Los borradores no deben sustituir documentación ya aceptada.
