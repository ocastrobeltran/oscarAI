# Glossary

## Términos clave

- ADR: Architectural Decision Record.
- C4: modelo de contexto, contenedor, componente y código.
- MCP: protocolo para conectar herramientas externas.
- RAG: recuperación aumentada con generación.
- Qdrant: base vectorial para embeddings.
- Orchestrator: componente que coordina agentes y contexto.
- Knowledge Base: conocimiento curado listo para recuperación.
