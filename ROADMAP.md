# Roadmap documental y técnica

Este roadmap ordena la entrega del repositorio de arquitectura y la evolución del producto Oscar AI.

## Fase 0. Base documental

- Separar visión, alcance y objetivos.
- Publicar arquitectura base y stack objetivo.
- Formalizar ADRs fundacionales.
- Definir navegación entre documentos.

## Fase 1. Núcleo de plataforma

- Aterrizar el modelo C4.
- Completar el modelo de datos.
- Definir contratos API y autenticación.
- Establecer Docker, Compose y reverse proxy.

## Fase 2. Inteligencia y memoria

- Detallar la estrategia RAG.
- Diseñar Qdrant, embeddings y políticas de indexación.
- Especificar la estrategia de memoria persistente.
- Documentar el orquestador de agentes.

## Fase 3. Integraciones

- Publicar las guías de Azure DevOps, GitHub, Outlook, OneDrive, Laravel y MCP.
- Documentar patrones de autenticación y permisos.
- Establecer convenciones de trazabilidad y auditoría.

## Fase 4. Operación y entrega

- Completar CI/CD, backups y recuperación.
- Añadir guía de contribución, convenciones de código y mantenimiento.
- Mantener el changelog documental con cambios relevantes.

## Hitos sugeridos

| Hito | Resultado esperado |
| --- | --- |
| H1 | Núcleo documental estable y navegable |
| H2 | Arquitectura de plataforma y datos cerrada |
| H3 | Agentes, memoria e integraciones definidos |
| H4 | Operación, despliegue y gobierno listos |
